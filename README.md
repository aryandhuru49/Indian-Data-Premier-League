
# 🏏 Indian Data Premier League – IPL Data Visualization (2008–2023)

## 📌 Project Summary

This is an interactive web-based dashboard built to explore various aspects of the Indian Premier League (IPL) from 2008 to 2023 through rich visualizations. Rather than predictive modeling, this project focuses solely on **exploratory data analysis (EDA)** to extract meaningful patterns and trends in:

- 🧾 Auction expenditures and franchise strategies  
- 🏟️ Match results and venue-based performance  
- 🧑‍💼 Player statistics and evolving roles

All visualizations are created using Python libraries: **Plotly**, **Matplotlib**, **Seaborn**, and **Altair**.

---

## 🛠️ Running the Project Locally

1. Open a terminal in the project directory.
2. Start a local server:

```bash
python -m http.server 8000
```

3. Then open this URL in your browser:

```
http://localhost:8000/src/html/index.html
```

## 🧠 Abstract

This project delivers a feature-rich dashboard designed to visually interpret IPL data over 16 seasons (2008–2023). It utilizes clean datasets and focuses on revealing insights through descriptive analytics.

Visualization tools used:
- **Plotly** – Interactive dashboards and charts  
- **Seaborn** and **Matplotlib** – Statistical and aesthetic visualizations  
- **Altair** – Simple and declarative plots

The dashboard is structured into three sections:
1. **Auction Analysis**
2. **Game Insights**
3. **Team Performance**

Each tab includes dynamic elements and explanatory context to highlight:
- Financial decisions vs match outcomes  
- Win tendencies at specific venues  
- Player behavior and role evolution over time

## 📚 Introduction

The IPL blends competitive cricket with business dynamics. With structured data available from auctions to match stats, this project synthesizes it into an intuitive, exploratory platform.

### 🎯 Goals:
- Build an interactive IPL analytics dashboard  
- Make analysis approachable for tech and non-tech users  
- Apply advanced visual storytelling techniques learned through coursework

### 🔍 Core Analytical Sections:
1. **Auction Analytics** – Understand franchise spending, trends, and player picks
2. **Match Analysis** – Explore toss effects, ground influences, and season patterns
3. **Player Insights** – Track batting and bowling progress, key performers, and anomalies

The data story follows the IPL journey:  
**Auction Table → Game Field → Player Highlights**
